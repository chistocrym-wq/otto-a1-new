# Запуск «Тренажёра Отто» как Telegram Mini App

Приложение уже подключает официальный Telegram Web App SDK, сообщает Telegram о готовности, разворачивается на доступную высоту, учитывает безопасные отступы телефона и использует системную кнопку «Назад».

## 1. Опубликуйте приложение

Вариант с Bolt:

1. Загрузите содержимое этого проекта в GitHub.
2. Импортируйте репозиторий в Bolt.
3. Нажмите **Publish**.
4. Скопируйте итоговый адрес, начинающийся с `https://`.

Можно использовать Vercel, Netlify или другой статический хостинг. Команда сборки — `npm run build`, папка публикации — `dist`.

## 2. Создайте бота

1. Откройте в Telegram официального бота `@BotFather`.
2. Выполните `/newbot` и следуйте подсказкам.
3. Не вставляйте полученный токен в этот проект и не публикуйте его. Для текущей статической версии токен вообще не требуется.

## 3. Подключите Mini App

Для основной кнопки запуска откройте в BotFather настройки созданного бота и выберите **Bot Settings → Configure Mini App / Main Mini App**. Укажите опубликованный HTTPS-адрес.

Чтобы добавить кнопку возле строки сообщения, выполните `/setmenubutton`, выберите бота, задайте текст кнопки, например `Открыть тренажёр`, и вставьте тот же HTTPS-адрес.

После настройки приложение можно открывать из профиля или меню бота. Ссылка на основное приложение имеет вид:

`https://t.me/ИМЯ_БОТА?startapp`

## Важно

- Прогресс сейчас хранится на устройстве пользователя в браузерном хранилище Telegram.
- Для синхронизации между устройствами понадобится серверная база данных.
- Если позже появится сервер, данные `Telegram.WebApp.initData` необходимо проверять на сервере. Нельзя доверять `initDataUnsafe` для авторизации.
- После каждой новой публикации проверьте приложение в Telegram на Android и iPhone.
